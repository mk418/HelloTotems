# HelloTotems

A lean, opinionated totem manager for WoW Classic Era Shamans. Companion to [HelloHealer](https://github.com/mk418/HelloHealer) — handles the parts of Shaman play that don't fit a heal-target UI.

> **Heads up** — this is a personal work in progress. I build and evolve it as I play using it, so features land when I need them and design choices reflect my play style.

## Caveats

- Only works on Classic Era, no support for other game versions.
- Loads as a no-op for non-Shaman characters.
